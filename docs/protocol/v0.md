# Smart Neckband V0 Protocol

The V0 packet format is transport independent. UART, Bluetooth Classic SPP, and future BLE transports must send the same bytes.

All integer fields are little-endian. CRC is CRC-16/CCITT-FALSE over the header and payload, excluding the trailing CRC field.

## Header

| Field | Type | Bytes | Notes |
|---|---:|---:|---|
| magic | `uint16_t` | 2 | `0x4E53`, wire bytes `53 4E` |
| protocol_version | `uint8_t` | 1 | `1` |
| packet_type | `uint8_t` | 1 | `1` for ECG |
| payload_length | `uint16_t` | 2 | ECG payload is 48 bytes |
| packet_sequence | `uint32_t` | 4 | Monotonic packet sequence |
| timestamp_us | `uint64_t` | 8 | Monotonic device timestamp |

Header size: 18 bytes.

## ECG Payload

| Field | Type | Bytes | Notes |
|---|---:|---:|---|
| first_sample_index | `uint32_t` | 4 | Index of the first sample in this packet |
| sample_rate_hz | `uint16_t` | 2 | `500` |
| sample_count | `uint8_t` | 1 | `20` |
| flags | `uint8_t` | 1 | Bit flags below |
| samples | `uint16_t[20]` | 40 | Raw ADC counts, unfiltered |

ECG payload size: 48 bytes. Full ECG packet size with CRC: 68 bytes.

## Flags

| Bit | Name |
|---:|---|
| 0 | `LO_MINUS` |
| 1 | `LO_PLUS` |
| 2 | `ADC_CLIPPING` |
| 3 | `SAMPLE_LATE` |
| 4 | `SAMPLE_MISSED` |
| 5 | `SAMPLE_QUEUE_OVERFLOW` |
| 6 | `TRANSPORT_OVERFLOW` |
| 7 | `HISTORICAL_DATA` |

## Golden Vectors

The shared vectors live in `docs/protocol/v0_golden_vectors.json`. The first vector encodes one ECG packet with 20 samples from `2048` through `2067`, packet sequence `0x01020304`, timestamp `0x0102030405060708`, first sample index `4096`, and flags `LO_MINUS | ADC_CLIPPING`.
